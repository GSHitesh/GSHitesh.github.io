# portfolio-dark — Dark Mode First

Sai Hitesh Gorantla portfolio - Dark Mode First.

One-page portfolio site for **Sai Hitesh Gorantla** in the **Dark Mode First** aesthetic.
Pure HTML + CSS + a sprinkle of vanilla JS. No build step.

## Local preview
Open index.html in any modern browser, or:

```sh
python -m http.server 8080
```

## Deploy
A GitHub Actions workflow (.github/workflows/deploy.yml) publishes this site to GitHub Pages on every push to main. Enable Pages with **Source: GitHub Actions** in repo settings.
